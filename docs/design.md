# Codex 旧回放重置设计

日期：2026-11-11。用户已确认采用本地清理代理串联 CC Switch 的方案。

## 目标

保留 CC Switch 路由与本地聊天记录，在 AgentRouter Responses 上游资源切换后，按会话手动清理旧回放以尝试恢复原会话续聊。

## 实现

Codex 请求先经过本地 HTTP 清理代理，再原样交给原 CC Switch 路由。页面提供重置和接入管理；后台处理配置恢复及代理生命周期；纯策略模块按指纹投影请求副本。

一次点击标记所选会话，下一条完整请求捕获旧回放。旧 reasoning 与资源 id 在请求副本中清理，可见历史、工具参数、结果和 call_id 保持。新回放保留，子代理和独立 fork 分别操作。

接入单处修改 base_url 并保存原地址。代理独立运行，Codex++ 启动前恢复；解除和显式停止可撤销接入。存在引用式历史、加密压缩或不完整工具配对时拒绝清理。

## 验收

使用合成历史和本地模拟上游，验证原对象不变、指纹持久、HTTP/SSE 透传、活动请求保护、取消、配置最小修改与恢复，以及页面注册。安装后核对管理器加载状态和实际界面。真实 AgentRouter 故障恢复留给故障会话下一条正常消息验证，不自动发消息。
