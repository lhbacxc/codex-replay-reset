# v0.1.1 旧回放重置

为 Codex++、CC Switch 路由和 AgentRouter Responses 提供手动旧回放重置，保留本地聊天历史、工具结果与配对关系。附带 ZIP 可作为本地拓展安装，源码仓库包含完整实现、测试和 AI 开发入口。

0.1.1 修复宿主会话索引返回“没有找到会话”时的阻断问题，增加原生 JSONL 只读后备检查。运行态、身份、结束事件、工具配对与文件变化检查继续保留。

使用前先在 CC Switch 开启 Codex 路由，按 README 安装拓展、接入本地代理，通过 Codex++ 重启 Codex 并恢复原会话，再点击“重置旧回放”。安装包不包含用户连接状态、控制凭证或聊天内容。

本地 27 项测试、语法检查和打包验证通过；实际使用已确认功能成功。完整适用范围及安装步骤见仓库 README，后续开发从 AGENTS.md 与 AIREADME.md 开始。
